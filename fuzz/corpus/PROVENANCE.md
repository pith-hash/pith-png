# Fuzz corpus provenance

Seeds for the PNG fuzz corpus, byte copies of the monorepo `fuzz/corpus/png/`
seeds (generated by `lab/phash_oracle.py`, the same run that wrote the
conformance fixtures in `tests/fixtures/`). The 48x40-class images here
exercise full-colour, palette+tRNS and 16-bit grey decode paths beyond the
small conformance fixtures, at sizes large enough to span multiple
compression blocks.

`sha256` below is the first 16 hex digits of the file's SHA-256; the replay
test (`tests/fuzz_corpus.rs`) pins the same digests, so a corrupted seed is
caught before it reaches a decode.
